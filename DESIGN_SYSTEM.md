# 🎹 Shraddha Music School - Design System

## Color Palette

| Color Name | Hex Code | Usage |
|-----------|----------|-------|
| Deep Navy | #1a1a2e | Primary, backgrounds, text |
| Vibrant Purple | #667eea | Accents, links, CTAs |
| Rich Magenta | #764ba2 | Secondary accents, highlights |
| Light Gray | #f0f0f0 | Backgrounds, subtle elements |
| Warm Gold | #ffd60a | Testimonials, achievements |
| Piano Black | #000000 | Piano key references |

## Typography

### Heading Font
- **Font Family**: Georgia, serif
- **Usage**: Main headings, page titles
- **Characteristics**: Elegant, sophisticated, artistic

### Body Font
- **Font Family**: Segoe UI, sans-serif
- **Usage**: Body text, descriptions, content
- **Characteristics**: Clean, modern, highly readable

### Accent Font
- **Font Family**: Courier New, monospace
- **Usage**: Brand names, special emphasis
- **Characteristics**: Modern, technical, distinctive

## Component Guidelines

### Buttons
- Primary: Deep Navy background, White text
- Secondary: Vibrant Purple background, White text
- Hover states: Darker variations

### Cards
- Background: White with subtle shadows
- Borders: Light Gray (#f0f0f0)
- Accent border: Vibrant Purple

### Hero Section
- Gradient: Deep Navy (#1a1a2e) to Medium Blue (#2d3561)
- Text: White, centered
- Accent elements: Vibrant Purple
